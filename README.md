# Каталог новостроек Евпатории

Проект сайта-каталога недвижимости Николая Черныш.

## Статус

Репозиторий создан. Исходный код сайта и публикация пока не выполнены. Не считать этот репозиторий запущенным сайтом.

## Задачи сайта

- Удобный мобильный каталог жилых комплексов Евпатории и пригорода.
- Раздельный просмотр квартир и апартаментов.
- Карточки ЖК с проверенными характеристиками, реальными фотографиями, диапазонами цен и авторским комментарием.
- Фильтры, ипотечные программы и форма обращения к риелтору.
- Закрытая административная панель для обновления карточек, фотографий и цен.
- Обработка заявок на защищённом сервере с учётом требований к персональным данным.

## Важные ограничения

- Не публиковать телефоны покупателей, заявки, личные документы, пароли, ключи, файлы `.env` или данные CRM.
- Не делать публичных переходов на сайты застройщиков: внутренние источники для проверки информации допустимы.
- Не принимать реальные заявки до настройки безопасного серверного хранения и согласия на обработку данных.
- Данные о ценах и условиях ипотечных программ датировать и проверять по официальным источникам.

## Следующие шаги

1. Найти или восстановить актуальную версию исходного кода каталога.
2. Перенести материалы ЖК и фотографии, проверить лицензии и достоверность.
3. Собрать и проверить мобильный интерфейс.
4. Настроить тестовую публикацию только демонстрационной части.
5. Подключить сервер, админку и формы заявок после настройки защиты.
